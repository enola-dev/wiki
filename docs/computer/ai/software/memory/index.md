# LLM and Agent Memory

Index and overview of architectures, frameworks, and software providers for persistent LLM and AI agent memory.

## Concepts & Architecture

- [[memory]] - Foundational concepts, cognitive taxonomy (episodic, semantic, procedural, working), and architectural paradigms for LLM agent memory.

## Articles & Software Providers

- [[cognee]] - Open-source topological memory engine organizing unstructured data into knowledge graphs and vector embeddings.
- [[mem0]] - Open-source personalized memory layer with multi-level scoping (user, agent, session) and automated fact extraction.
- [[letta]] - Stateful agent operating system with virtual context memory paging (core, recall, archival).
- [[graphiti]] - Open-source temporal knowledge graph engine for dynamic agent memory and entity tracking over time (powering Zep).
- [[cmem]] - Open-source persistent memory stream and context compressor tailored for coding agents (Claude Code, OpenClaw).
- [[memory-store]] - AI-native memory layer and company brain by Julep AI with Model Context Protocol (MCP) support.
- [[langmem]] - Long-term memory SDK by LangChain for semantic user profiles, episodic interaction summaries, and procedural rules.
- [[honcho]] - User-modeling and natural language plasticity memory platform by Plastic Labs.
- [[supermemory]] - Open-source second brain and context engine connecting external data to LLMs via MCP.
- [[hipporag]] - Neurobiologically inspired multi-hop memory framework using Personalized PageRank on knowledge graphs.
- [[hermes-memory-providers]] - Survey of pluggable external memory providers in Hermes Agent (OpenViking, Holographic HRR, Hindsight, RetainDB, ByteRover).
